## Проверки

Новые регрессии проверяют отсутствие секрета, одновременные запросы с лимитом
10000, дневной/общий потолки, границу UTC, повторные выплаты, запрет выплат до
LIFE #1 и доступ к RPC. Бот проверен с имитацией Telegram API: реальные сообщения
не отправлялись. Юридические страницы проверены в браузере на ширинах 320, 390
и 1365; «Ещё» — на 13 языках. Найден и исправлен выход длинного заголовка за экран.
Полный прогон: 48/48 тестов прошли локально. GitHub Actions run 37929801391 также завершился success.

На 9 октября после обновления rewards v18 и telegram-progress v17 отвечают HTTP 200,
ok:true, версия 20261009-prelaunch-1, configuration_ready:true; неверные данные входа
отклоняются с HTTP 401. mission-control возвращает ok:true и entries.
Предыдущие миграции 20261007/20261008 применены. Аудитор безопасности Supabase
не сообщил WARN/ERROR; INFO о RLS без публичных политик соответствует закрытым
серверным таблицам. Новая миграция и обе функции выложены. До/после: 6 игроков, 2071 очко суммарно,
17 событий наград, 0 реферальных событий — данные игроков не изменились.
RPC по-прежнему недоступен ролям anon/authenticated.

## До публикации и запуска

1. Сверить юридические документы с владельцем: уточнить реквизиты оператора,
   рабочий частный контакт и процесс обработки запросов; не выдумывать их.
2. Серверная часть закрыта: миграция применена, rewards и telegram-progress
   выложены одной версии 20261009-prelaunch-1; configuration_ready:true
   подтвердил наличие CIPHER_SECRET без раскрытия значения. Проверка реального
   подписанного входа игрока и Telegram API ещё нужна.
3. Проверить текущий webhook бота перед подключением нового. После публикации
   legal-страниц активировать команды и webhook с отдельным секретом. Подготовка
   кода не означает, что команды уже работают в Telegram.
4. В BotFather проверить Menu Button, Mini App URL, short name; установить
   https://moonkattymky.github.io/moonkatty-game/privacy.html. Проверить права
   бота в канале. Доступ к BotFather и реальный Telegram-вход здесь не подтверждены.
5. Пройти LIFE #1 на физических iPhone и Android: вход, награда, приглашение,
   подписка и повторное открытие. Эмуляция размеров экрана этого не заменяет.
6. После публикации выполнить tools/verify-live.cjs. Пока main не изменён,
   старая доступная игра не подтверждает публикацию этого обновления.

## Что не входит в завершённые исправления

- Полная редактура всех 1800+ строк каждым носителем языка не выполнена.
- Проверка 10-значного кода LIFE #3 остаётся клиентской. Серверный повтор
  этапов для наград сохраняется, но он не делает клиентский секрет невидимым.
- Уведомления, магазин, сезоны и офлайн-режим не добавлены.
- YouTube OAuth не включён. Предложение из исходного задания включить награды
  за подписку необходимо пересмотреть: правила YouTube API III.F.3 запрещают
  вознаграждение за просмотры, лайки, подписки и другие действия, включая
  косвенное стимулирование. Кодовые слова только из видео тоже требуют пересмотра.
- Правила Telegram касаются продвижения сторонних токенов в официальном
  сообществе Mini App, не только внутри игры. Посты каналов здесь не изменялись.

Официальные источники: https://core.telegram.org/bots/blockchain-guidelines
и https://developers.google.com/youtube/terms/developer-policies .

Итог: это подготовленный кандидат, а не подтверждённый допуск к запуску.
Не заявлять «всё готово», пока внешние пункты не закрыты.
